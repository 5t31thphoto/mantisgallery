M5Stack Core2 · Mantis Gallery

SD-card gallery. Images in /images, subfolders as albums. Random shuffle with no repeats until the album rolls over. Slideshow is off until you long-press the screen.

1Install firmware

Chrome / Edge, USB cable to the Core2. Hold the side button if the port does not appear.

↓Direct downloads

Only these files:

Merged firmware mantis-gallery.bin — app image at offset 0x10000.
Image specification IMAGE_SPEC.txt — 320×240, .mg format, SD layout, controls.

2Prepare the SD card

FAT32 card. Create /images. Put JPG/PNG there, or convert with tools/mg_convert.py for the fast .mg format. Files in /images = default album. Subfolders = extra albums.

3Controls

Default album (files in /images):

Hold B — yellow→red bar; hold until full → random subfolder · Swipe right / left — next / previous image · Long-press screen — slideshow on/off

Subfolders:

A / C — prev / next subfolder · Short B — back to default · swipes and long-press same as above

Slideshow (starts off):

Random 5–8 s per image · Tap — stay on current photo 2× as long · swipes still change image · long-press again to exit · Hold C — power off

No on-screen labels during playback.
